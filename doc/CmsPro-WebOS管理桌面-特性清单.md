# CmsPro WebOS 管理桌面 · 特性清单

> 文档版本：1.2.0 | 更新日期：2026-09-29
> 应用版本：1.2.0 | 应用 ID：`cmspro.webos`

## 一、应用定位

WebOS 管理桌面是 CmsPro 后台的可选交互层，不替换系统后台框架。应用读取当前管理员可见菜单，并通过同源 iframe、多窗口和任务栏提供桌面式操作体验。

## 二、功能清单

| 功能 | 说明 | 数据来源 |
|---|---|---|
| 桌面快捷方式 | 添加、移除、拖动后台菜单入口 | 当前管理员菜单 + WebOS 工作区 |
| 开始菜单 | 仅展示 `admin` 后台顶级菜单，右侧按 `app_id` 聚合应用，可搜索和固定入口 | `MenuService::userMenus()` + WebOS 后台菜单过滤 + 应用目录 |
| 应用独立窗口 | 每个应用只创建一个窗口，左侧仅展示当前应用菜单；支持拖动、缩放、最小化、最大化、关闭 | 浏览器运行时 |
| 任务栏 | 紧凑展示固定入口、运行窗口、通知、账号和时钟，可设为上、下、左、右 | 工作区 + 系统接口 |
| 应用市场 | 浏览远程市场，失败时降级到本地可安装应用 | 系统应用市场 API |
| 安装应用 | 自动识别 `admin`、`user`、`home` 菜单声明，按实际终端分别选择顶级菜单挂载位置，安装后可创建后台桌面入口 | 系统安装 API |
| 已安装应用 | 查看应用状态、打开应用菜单、固定到桌面 | `apps` 表 |
| 未安装应用 | 重新列出本地已发现但尚未安装的应用，并提供安装入口 | 系统本地应用 API |
| 应用更新 | 检查并执行应用更新 | 系统更新 API |
| 安装记录 | 展示最近 30 条应用操作记录 | `app_operation_logs` 表 |
| 入口管理 | 集中管理桌面快捷方式和可用菜单 | 工作区 + 当前管理员菜单 |
| 通知中心 | 显示系统推送与待办，支持全部已读 | 系统通知 API |
| 账号菜单 | 个人设置、锁定桌面、退出登录 | 系统认证 API |

## 三、交互规则

1. 双击桌面图标打开窗口；拖动图标后自动保存位置。
2. 开始菜单中的图钉按钮用于添加或移除桌面快捷方式。
3. 同一应用只保留一个运行窗口；打开该应用的其他菜单时，会在原窗口内切换内容和选中菜单。
4. 桌面窗口仅加载以 `/` 开头的站内路径，拒绝外部地址进入 iframe。
5. 本地和市场安装沿用 CmsPro 安装器。弹窗根据应用清单自动显示后台、用户端、前端菜单挂载项；未声明的终端不显示，不选择父级则安装为独立顶级菜单。
6. 开始菜单左侧仅保留后台 `admin` 顶级菜单层级，不显示 `user`、`home` 菜单；右侧相同 `app_id` 的后台菜单只显示一个应用卡片。

## 四、数据结构

### `app_cmspro_webos_workspaces`

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | BIGINT | 主键 |
| `admin_user_id` | BIGINT | 管理员 ID，唯一 |
| `desktop_items` | JSON | 桌面快捷方式、路径和网格位置 |
| `preferences` | JSON | 壁纸、任务栏、时钟和动效偏好 |
| `status` | TINYINT | 0 禁用，1 启用 |
| `create_time` | TIMESTAMP | 创建时间 |
| `update_time` | TIMESTAMP | 更新时间 |

## 五、安全边界

- 页面与 API 均使用 `web`、`auth:admin` 中间件。
- 工作区记录强制绑定当前管理员 ID，客户端不能提交其他管理员 ID。
- 桌面路径仅允许站内绝对路径，禁止协议地址和 `//` 协议相对地址。
- 桌面入口最多 48 个；标题、图标类名、坐标和偏好均做白名单与边界处理。
- 所有动态文本写入 DOM 前进行 HTML 转义。
