# CmsPro WebOS 管理桌面 · 使用指南

> 文档版本：1.4.6 | 更新日期：2026-09-29
> 应用版本：1.4.6 | 应用 ID：`cmspro.webos`

## 一、环境要求

| 项目 | 要求 |
|---|---|
| PHP | >= 8.3 |
| CmsPro | >= 5.0.0 |
| 数据库 | MySQL 5.7+ / MariaDB 10.3+ |
| 浏览器 | 支持 `backdrop-filter`、Pointer Events 与原生 `fetch` 的现代浏览器 |
| 推荐视口 | 宽度不低于 960px，推荐 1440×900 及以上 |

## 二、安装与启用

1. 进入后台“应用管理”。
2. 在本地应用列表中找到“WebOS 管理桌面”。
3. 选择后台菜单挂载位置，执行安装。
4. 启用应用并刷新后台菜单。
5. 点击“WebOS 管理桌面”，系统以新窗口打开 `/admin/cmspro/webos`。

安装后检查：

| 检查项 | 预期结果 |
|---|---|
| 数据表 | 存在 `app_cmspro_webos_workspaces` |
| 后台菜单 | 显示“WebOS 管理桌面” |
| 静态资源 | `public/apps/cmspro.webos/` 已由安装器发布 |
| 页面 | 显示壁纸、桌面图标和底部任务栏 |

## 三、桌面操作

- 双击桌面图标打开应用窗口。
- 桌面快捷方式、任务栏固定与运行图标、开始菜单应用卡片都显示对应应用的真实图标；系统内置菜单和 WebOS 内置窗口保留原有图标。
- 在开始菜单应用卡片上点击 `+` 会把该应用固定到桌面，桌面图标名称使用应用名称（而不是该应用第一个菜单的名称）。
- 在桌面图标上点击右键会打开操作菜单：**打开应用**（菜单入口则显示“打开”）、**删除图标**（仅移除桌面快捷方式）。图标属于已安装应用且该应用不是系统应用时，还会显示 **卸载应用**：
  - 应用处于启用状态时，先提示先禁用应用，并可直接在提示中禁用；
  - 应用已禁用时，进入与“已安装”列表一致的卸载确认流程，需要输入应用名称才能卸载；
  - “删除图标”只影响当前管理员的桌面布局，不会卸载应用。
- 按住桌面图标拖动，松开后位置会保存到当前管理员工作区。
- 点击任务栏上的 CMSPRO 标志打开开始菜单；左侧“常用”优先显示经常打开的入口，其余分组只显示后台 `admin` 顶级菜单。用户端 `user` 和前端 `home` 菜单不会出现在 WebOS 开始菜单中。
- 开始菜单、通知中心和账号菜单处于展开状态时，点击桌面空白区域、桌面图标或任务栏其他位置会立即收起；在面板内部操作（切换分组、搜索、查看通知）不会收起面板。
- 右侧的应用卡片打开应用独立窗口；系统内置菜单以文件夹显示，点击后在独立窗口左侧列出该文件夹子菜单，并默认打开第一项。
- 每个应用在独立窗口中运行，窗口左侧只显示当前应用的菜单；选择同一应用的其他菜单会在原窗口内切换。标题栏菜单按钮可收起或展开左侧菜单；应用只有一个菜单时首次打开默认收起，不占用内容空间。
- 普通应用窗口标题显示该应用图标，读取顺序与应用中心一致；标记为系统应用的窗口、系统菜单文件夹及 WebOS 内置窗口继续显示 CMSPRO Logo。
- 窗口标题栏支持拖动，右下角支持缩放；右上角依次为最小化、最大化和关闭。
- 点击任务栏中的运行图标可聚焦或最小化对应窗口。
- 点击任务栏末端窄条可最小化全部窗口并显示桌面。
- 任务栏时间随任务栏方位自适应：停靠在上方或底部时第一行显示年月日、第二行显示周几与时间；停靠在左侧或右侧时依次显示年月日、周几、时间三行。
- 点击任务栏时间弹出日历：显示当前月份与“今天”信息，可用左右箭头翻月、点击“回到今天”回到当月，点击任意日期会高亮并在标题下方显示该日期与星期；点击面板外部或按 Esc 收起。
- 开始菜单底部提供“锁定”“退出登录”“OS 设置”。OS 设置可调整任务栏上、下、左、右停靠位置、壁纸、12/24 小时时钟、秒数和界面动效，设置按管理员自动保存。

## 四、应用中心

应用中心包含六个界面：

1. **应用市场**：优先读取远程市场；远程不可用时显示本地未安装应用。
2. **已安装**：以列表形式管理应用状态与操作入口，支持状态筛选和全套应用操作。
3. **未安装**：列出本地已发现但尚未安装的应用，可再次进入安装流程。
4. **应用更新**：调用系统更新检查并执行单应用更新。
5. **安装记录**：查看最近安装、升级、启用、禁用与卸载记录。
6. **入口管理**：添加、打开或移除桌面快捷方式。

### 图标来源

“已安装”和“未安装”应用的图标按应用根目录 `icon.svg`、`icon.png`、当前 `manifest.json` 的 `icon` 顺序读取；前一项不存在或加载失败时自动使用下一项。同一套规则同时用于桌面快捷方式、任务栏图标和开始菜单应用卡片。

“应用市场”的图标来自远程市场返回的 `icon` 字段：绝对地址直接使用，相对路径按系统应用市场配置的地址（`apps.market.api_url`）拼接；加载失败时降级为通用占位图标。

### 应用市场状态

应用市场列表会与本机已安装应用比对：未安装显示“安装”，已安装且版本一致显示“已安装”，远程版本高于本地版本显示“更新”。版本比较规则与系统应用市场一致。

### 已安装应用列表

列表按“应用信息 / 状态 / 操作”三列展示，顶部提供搜索、状态筛选（全部状态、已启用、已禁用）和“上传安装”按钮，统计行显示应用总数与已启用数量。“未安装”和“应用市场”界面只保留搜索，不提供状态筛选。

- 状态列只显示启用开关，开关状态通过提示文字和无障碍标签表达；操作后会刷新应用状态与后台菜单。
- “打开”进入该应用的 WebOS 窗口；应用没有可访问的后台菜单时按钮为禁用态。
- “手动”直接上传本地 `.zip` 升级包完成手动升级，“导出”直接将应用代码与数据表打包下载。
- “更多操作”菜单提供管理入口（应用有可访问后台菜单时）、备份、文档、设置（存在 `config_groups` 时）和卸载（非系统应用）：

| 操作 | 行为 |
|---|---|
| 管理入口 | 单独把该应用的某个菜单添加到桌面或移出桌面 |
| 备份 | 查看历史备份并新建备份；可下载备份文件 |
| 文档 | 浏览应用 `doc/` 目录下的 Markdown 文档，支持下载 |
| 设置 | 读取并保存应用 `config_groups` 配置项 |
| 卸载 | 输入应用名称确认后卸载，需先禁用应用 |

上述操作直接复用系统应用管理接口（`/api/admin/apps/*`），不重复实现安装器逻辑。“上传安装”用于安装新的应用包，与系统“应用管理”页面的上传安装等价。操作弹窗高度不超过视口，内容过长时弹窗主体滚动，标题与关闭按钮始终可见。

安装弹窗会先读取应用清单并自动判断菜单终端：声明 `menus` 时显示“后台菜单挂载位置”，声明 `user_menus` 时显示“用户端菜单挂载位置”，声明 `home_menus` 时显示“前端菜单挂载位置”。每个终端都可选择现有顶级菜单；不选择则作为独立顶级菜单安装。若应用只声明后台菜单，弹窗只显示后台挂载项。

选择“创建桌面快捷方式”或“两者都创建”后，WebOS 会在安装完成且存在可访问的后台菜单时，把应用首个后台菜单入口固定到桌面。仅声明用户端或前端菜单的应用不会创建 WebOS 桌面快捷方式。

## 五、通知与账号

- 点击任务栏铃铛查看待办和最近通知，可执行“全部已读”。
- 点击管理员头像进入账号菜单：**个人设置**在独立窗口内打开传统后台的个人中心页（`/admin/account`）；**修改密码**在弹窗中完成修改；也可使用开始菜单底部快速锁定桌面或退出登录。任务栏位置请到 OS 设置中调整，账号菜单不再提供该设置。
- “修改密码”弹窗需要依次填写原密码、新密码与确认新密码：新密码 6-20 位、不能与原密码相同、两次输入需一致；校验不通过会即时提示，原密码错误等由系统返回的信息同样会以提示形式展示，修改成功后下次登录使用新密码。
- WebOS 不展示网络信号或声音控件。

## 六、测试与验证

```bash
php artisan test app/Apps/CmsproWebos/Tests
```

应用测试覆盖：未登录访问、桌面页面、工作区读取与保存、任务栏位置校验、偏好合并、站外路径拦截、管理员数据隔离、应用图标统一规则、应用市场图标与安装升级状态、已安装列表视图与状态筛选、已安装应用操作接口复用等行为。

## 七、卸载与回滚

通过后台卸载时，`Install::uninstall()` 会回滚应用迁移并删除工作区表，安装器同时移除应用菜单、权限与已发布资源。

人工回滚前必须备份数据；脚本位于 `Database/rollback.sql`。该操作会删除所有管理员桌面配置，无法自动恢复。

## 八、常见问题

### 页面一直停留在加载状态

检查应用是否已启用、静态资源是否已发布，并在浏览器开发者工具中确认工作区与目录接口未返回 401/403/500。

### 安装应用后没有自动出现桌面图标

目标应用必须声明至少一个可访问的后台菜单，且当前管理员拥有该菜单权限。可在“入口管理”中手动添加已授权菜单。

### 为什么小屏幕显示提示页

多窗口桌面需要足够的横向空间。宽度低于 960px 时会显示视口提示，避免窗口控件被遮挡。
