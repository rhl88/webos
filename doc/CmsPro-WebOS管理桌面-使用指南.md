# CmsPro WebOS 管理桌面 · 使用指南

> 文档版本：1.9.79 | 更新日期：2026-10-01
> 应用版本：1.9.79 | 应用 ID：`cmspro.webos`

## 一、环境要求

| 项目 | 要求 |
|---|---|
| PHP | >= 8.3 |
| CmsPro | >= 5.0.0 |
| 数据库 | MySQL 5.7+ / MariaDB 10.3+ |
| 浏览器 | 支持 `backdrop-filter`、Pointer Events 与原生 `fetch` 的现代浏览器 |
| 推荐视口 | 宽度不低于 960px，推荐 1440×900 及以上 |

## 二、安装与启用

1. 进入后台“应用管理”。
2. 在本地应用列表中找到“WebOS 管理桌面”。
3. 选择后台菜单挂载位置，执行安装。
4. 启用应用并刷新后台菜单。
5. 点击“WebOS 管理桌面”，系统以新窗口打开 `/admin/cmspro/webos`。

应用启用后，传统后台（所有后台页面）右下角会出现一个蓝色书本样式的**「进入 WebOS」悬浮入口**：鼠标悬停时卡片像翻书一样翻开、显示“进入 WebOS”文字，点击即进入 `/admin/cmspro/webos`。若右下角同时出现版本升级浮动按钮，入口会自动上移避让。

安装后检查：

| 检查项 | 预期结果 |
|---|---|
| 数据表 | 存在 `app_cmspro_webos_workspaces` |
| 后台菜单 | 显示“WebOS 管理桌面” |
| 静态资源 | `public/apps/cmspro.webos/` 已由安装器发布 |
| 页面 | 显示壁纸、桌面图标和底部任务栏 |

## 三、桌面操作

- 双击桌面图标打开应用窗口。
- 桌面快捷方式、任务栏固定与运行图标、开始菜单应用卡片都显示对应应用的真实图标；系统内置菜单和 WebOS 内置窗口保留原有图标。
- 在开始菜单应用卡片上点击 `+` 会把该应用固定到桌面，桌面图标名称使用应用名称（而不是该应用第一个菜单的名称）。
- 在桌面图标上点击右键会打开操作菜单：**打开应用**（菜单入口则显示“打开”）、**删除图标**（仅移除桌面快捷方式）。图标属于已安装应用且该应用不是系统应用时，还会显示 **卸载应用**：
  - 应用处于启用状态时，先提示先禁用应用，点击“禁用应用”成功后会自动弹出卸载确认界面；
  - 应用已禁用时，进入与“已安装”列表一致的卸载确认流程，需要输入应用名称才能卸载；
  - “删除图标”只影响当前管理员的桌面布局，不会卸载应用。
- 在桌面空白处点击右键会打开桌面菜单：**刷新**（重新加载工作区、菜单目录并重绘桌面、开始菜单与任务栏）、**查看**（悬停展开子菜单：**大图标 / 中图标 / 小图标**三档切换，当前档位带勾选标记，默认中图标——与原布局一致；切换后立即按新档位重排桌面，图标尺寸偏好随工作区持久化）、**设置背景**（打开 OS 设置并定位到背景设置）、**个性设置**（打开 OS 设置的基本设置）、**显示桌面**（最小化全部窗口）。该菜单只在桌面区域生效，应用窗口（含应用中心）、任务栏、开始菜单等面板内右键不会出现桌面菜单。
- 停用（禁用）应用的桌面图标不再占位：图标可移入停用应用的格子，新增入口也可落在其空行；应用重新启用后若原坐标被占用，自动落到第一个空白格显示（未被占用则回原位）。
- 菜单与图标可见性和框架后台完全对齐：普通管理员只授权应用子菜单而未授权父级分组时，WebOS 目录自动补全祖先链（如 管理 → 应用分组 → 子菜单），与框架后台菜单一致；桌面/任务栏图标按「已分配」过滤，角色收回授权后对应图标不再显示。应用中心入口与应用中心/WebOS 升级提醒仅对超级管理员（super_admin）开放，非超管工作区重置后桌面为空。
- 按住桌面图标拖动，松开后位置会保存到当前管理员工作区。
- 点击任务栏上的 CMSPRO 标志打开开始菜单；任务栏停靠在左侧或右侧时，开始菜单从开始按钮下方展开（水平方向贴任务栏）。标题栏品牌标识与关闭按钮之间显示“搜索菜单与应用”输入框，输入即过滤当前分组的菜单与应用。左侧“常用”优先显示经常打开的入口，其余分组只显示后台 `admin` 顶级菜单。用户端 `user` 和前端 `home` 菜单不会出现在 WebOS 开始菜单中。
- 开始菜单、通知中心和账号菜单处于展开状态时，点击桌面空白区域、桌面图标或任务栏其他位置会立即收起；在面板内部操作（切换分组、搜索、查看通知）不会收起面板。
- 右侧的应用卡片打开应用独立窗口；系统内置菜单以文件夹显示，点击后在独立窗口左侧列出该文件夹子菜单，并默认打开第一项可由窗口内容区承载的菜单（打开方式为“新建窗口”或“弹窗网页”的菜单会被跳过）。文件夹内若还有下级分组，同样按层级展开收起。
- 每个应用在独立窗口中运行，窗口左侧只显示当前应用的菜单。菜单按后台声明的层级以树形显示，不再平铺：含下级的菜单显示为分组，点击分组标题即可展开或收起，同级分组互斥（展开一个自动收起其他），首次打开会自动展开当前页面所在的分组链路。选择同一应用的其他菜单会在原窗口内切换，不会重新加载整个窗口。标题栏菜单按钮可收起或展开整个左侧菜单；应用只有一个可访问菜单时首次打开默认收起，不占用内容空间。
- 窗口左侧菜单支持后台声明的四种打开方式：**嵌套网页**（`_iframe`，在窗口内容区用 iframe 承载，默认值）、**路由模式**（`_component`，AJAX 拉取 HTML 片段直接注入窗口内容区，片段内脚本会自动执行，注入后重新渲染 layui 组件）、**新建窗口**（`_blank`，浏览器新标签页打开，允许 http(s) 外链以便跳转第三方系统）、**弹窗网页**（`_layer`，用 layui 弹层打开，尺寸 80% × 80% 且支持最大化）。点击“新建窗口”或“弹窗网页”类菜单只打开对应标签页或弹层，窗口内容区与侧栏高亮均保持不变；iframe 与片段注入两种承载方式互相切换时只重建内容区，不会重建窗口。路由模式页面请求失败时内容区显示错误提示，401 会跳转登录页。路由模式片段运行在桌面页同一文档中，可直接复用传统后台的 CSS 与 JS 环境（pear、layui、font-awesome、权限变量均已就绪），片段内脚本按文档顺序执行。
- 普通应用窗口标题显示该应用图标，读取顺序与应用中心一致；标记为系统应用的窗口、系统菜单文件夹及 WebOS 内置窗口继续显示 CMSPRO Logo。标题栏中的应用 SVG/PNG 图片图标以白色为底，字体图标保持原彩色底，CMSPRO Logo 保持透明底。
- 应用声明了前台（home）菜单时，窗口标题栏「收起左侧菜单」按钮左侧会出现文字下拉按钮「前台 ▾」（固定宽度 58px、高度撑满标题栏）：点击展开该应用的前台菜单列表（下拉项仅显示菜单名称，不带图标），点击菜单项以浏览器新标签页打开前台地址；下拉默认锚定「收起左侧菜单」左侧展开。应用没有前台菜单时不显示该按钮，前台菜单读取失败时静默降级，不影响窗口本身。
- 窗口标题栏支持拖动，右下角支持缩放；右上角依次为最小化、最大化和关闭。
- 点击任务栏中的运行图标可聚焦或最小化对应窗口；右键运行图标可打开、还原、最大化、最小化、关闭窗口，并可固定到任务栏或解除固定。已固定的应用打开后不再在运行区重复显示图标，而是复用固定图标（底部出现运行指示条，点击在聚焦与最小化之间切换，右键可操作窗口）。
- 右键任务栏固定图标可打开应用、解除固定，非系统应用还可直接发起卸载。
- 点击任务栏末端窄条可最小化全部窗口并显示桌面。
- 任务栏时间随任务栏方位自适应：停靠在上方或底部时第一行居中显示年月日、第二行显示周几与时间；停靠在左侧或右侧时依次显示年月日、周几、时间三行。
- 点击任务栏时间弹出日历：显示当前月份，日期格下方标注农历（初一显示月名）与二十四节气，标题下方同步显示选中日期的农历与节气；可用左右箭头翻月，点击任意日期会高亮，“回到今天”按钮仅在选中非今天日期时显示，点击后回到当月并清除选择；点击面板外部或按 Esc 收起。
- 开始菜单底部提供“锁定”“退出登录”“OS 设置”，锁定与退出登录之间显示**版权信息条**，文案与框架后台页脚一致（CMSPRO 链接 + 系统版本号 + © 2015-当年动态年份 + Holley 链接）；桌面页面标题同步动态显示「CMSPRO v{系统版本} · WebOS v{应用版本}」。OS 设置窗口分为三个 Tab：**基本设置**（任务栏停靠位置、12/24 小时时钟、秒数、界面动效、窗口默认尺寸）、**背景设置**（壁纸显示风格切换、自定义壁纸上传、当前壁纸预览与自定义壁纸库）与**系统设置**（应用窗口多选项卡、覆盖传统后台、重置工作区），设置按管理员自动保存。
- 系统设置中可开启**应用窗口多选项卡**（默认关闭）：开启后新打开的应用窗口点击左侧菜单时以选项卡方式打开页面，选项卡条显示在窗口标题栏按钮区（从标题栏左侧展开，最小化/最大化/关闭按钮始终贴最右），可点击切换、点叉关闭；同一路径复用既有选项卡，切换不重新加载页面（表单输入、滚动位置等页面状态保留）。开关仅对开启后新打开的窗口生效，已打开窗口保持原模式；应用中心、OS 设置、通知中心、官网动态等 WebOS 内置特殊窗口不启用多选项卡。
- 选项卡条溢出与右键操作：选项卡超出窗口宽度时显示左右切换按钮（`<` 选项卡 … 选项卡 `>`），点击箭头平滑滚动约一屏，按钮按滚动位置自动显隐（到头隐藏），激活选项卡自动滚入可视区；在选项卡上右键弹出菜单：**关闭当前 / 关闭其它 / 关闭全部**（右键同时聚焦所在窗口，关闭其它后保留项自动激活）。标题栏品牌区的应用名固定不变，其下方 small 副标题实时跟随当前激活选项卡的菜单名，选项卡全部关闭后副标题清空仅保留应用名。
- 系统设置中可开启**覆盖传统后台**：开启后访问传统后台首页（`/admin`）将直接进入 WebOS 桌面（仅影响首页，其它后台页面不受影响）；需要临时访问传统首页时，在地址后加 `?skip_webos=1` 即可绕过。**重置工作区**按钮带内联二次确认，确认后清空桌面与任务栏图标、全部设置恢复默认（自定义壁纸文件保留）。
- 背景设置支持自定义壁纸：点击“上传壁纸”选择本机图片（JPG、PNG、GIF、WEBP，不超过 5MB），上传成功后立即生效并保存到当前管理员工作区；点击“恢复默认”清除自定义壁纸回到系统壁纸。自定义壁纸仅保存在本应用壁纸目录（`public/apps/cmspro.webos/wallpapers/`），数据库只记录相对路径。
- “当前背景”卡片采用左右布局：左侧为当前壁纸预览，右侧为**自定义壁纸库**。壁纸库首次切到背景设置 Tab 时按需加载，仅展示当前管理员本人上传的壁纸，按上传时间倒序排列，每张显示缩略图、文件大小与上传时间；正在使用的壁纸带高亮边框与对勾标记。点击缩略图即切换为当前桌面背景并自动保存；点击缩略图下方的垃圾桶图标进入内联二次确认（“删除”/“取消”），确认后立即删除文件并从列表移除，若删除的正是当前使用的壁纸会自动回退到系统默认壁纸。列表读取失败时显示“重新读取”入口；新上传的壁纸会自动出现在列表中。窗口宽度低于 1180px 时左右布局降级为上下堆叠。
- OS 设置中的“窗口默认尺寸”用滑块按百分比设置默认宽度与高度（40%–100%，默认 78% / 80%）：百分比基于可用桌面区域（不含任务栏）计算，只影响之后新建的应用窗口，已经打开或手动调整过尺寸的窗口保持不变；应用中心与 OS 设置这两个 WebOS 内置窗口不受该设置影响，始终按出厂默认 78% / 80% 打开；窗口最小尺寸为 420 × 320 像素。窗口四条边和四个角均可拖拽调整宽高（拖动左/上边缘时窗口位置随之移动，右/下边缘固定对侧），最大化状态下不可调整。
- 超级管理员（super_admin）进入桌面后会自动打开**官网动态**窗口（普通管理员不显示）：固定尺寸 600×500，停靠桌面最右侧并垂直居中，可最小化、最大化与关闭。内容实时读取官网公开动态接口（与框架后台 dashboard 同源）：默认展示最新 6 条动态，每条含正文（http(s) 链接自动转为新窗口链接）、图片网格与发布时间；点击图片弹出全屏相册层预览，同一条动态的多张图片可左右切换（与框架后台一致，layui 异常时回退新标签页打开原图）；标题右侧「更多」在新标签页打开官网动态页；读取失败或暂无动态时显示“暂无动态”。该窗口自动打开不计入开始菜单“常用”统计。

## 四、应用中心

应用中心包含六个界面：

1. **应用市场**：顶部以 Tab 形式展示应用分类（“全部” + 各分类，来自市场分类接口），点击分类即时切换并清空列表，首次加载与切换分类的加载提示统一由列表底部的“正在读取应用市场…”承担；列表滚动到底部自动 Ajax 加载下一页；搜索框输入（防抖）后带关键词全量 Ajax 搜索远程市场（不限于已加载页面）；点击远程市场的应用卡片进入应用详情页，详情页中的“应用截图”按一行显示，超出部分点击轨道两侧的左右箭头切换，点击任一截图弹出全屏预览层，大图可用区域为视口的 90% × 90%（图片在该框内等比缩放，不拉伸变形），左右切换按钮叠加在预览层两侧留白中不挤占图片宽度，可在预览中继续切换（支持 `←` / `→` 方向键，按 `Esc` 或点击遮罩关闭）；远程不可用时显示本地可安装应用。
2. **已安装**：以列表形式管理应用状态与操作入口，支持状态筛选和全套应用操作。
3. **未安装**：列出本地已发现但尚未安装的应用，可再次进入安装流程。
4. **应用更新**：调用系统更新检查并执行单应用更新。打开应用中心窗口时会静默检查一次，存在可用更新时在左侧菜单「应用更新」右上角显示红色数量角标（超过 99 折叠为 `99+`），无更新或检查失败时不显示角标；进入该界面会按检查结果同步角标，单个应用升级成功后本地移除该项并递减角标数量（更新检查结果在服务端缓存 24 小时，升级动作不会清除，故不重新请求接口）。
5. **安装记录**：查看最近安装、升级、启用、禁用与卸载记录（切换到该界面时按需读取系统操作日志接口）。
6. **入口管理**：添加、打开或移除桌面快捷方式。下半区“可用菜单”以树结构展示：应用菜单按应用聚合为顶层节点（显示应用图标，标注菜单数），系统菜单按原生层级显示分支，菜单叶子显示自身图标；树默认全部收起，点击节点展开/收起，已固定的菜单显示“已固定”标签，未固定的提供“添加到桌面”按钮。应用节点与桌面入口行同样显示应用图标，纯菜单项保持字体图标。

### 图标来源

“已安装”和“未安装”应用的图标优先使用系统接口返回的 `icon_url`（服务端按应用根目录 `icon.svg`、`icon.png` 顺序返回），加载失败时降级为应用 `icon` 字段（字体图标或图片路径），仍无效时显示通用 `fa fa-cube` 占位图标。同一套规则同时用于桌面快捷方式、任务栏图标和开始菜单应用卡片。应用中心、安装弹窗与窗口标题栏中的 SVG/PNG 图片图标以白色为底，字体图标保持原彩色底。

“应用市场”的图标来自远程市场返回的 `icon` 字段：绝对地址直接使用，相对路径按系统应用市场配置的地址（`apps.market.api_url`）拼接；加载失败时降级为通用占位图标。

### 应用市场状态

应用市场列表会与本机已安装应用比对：未安装显示“安装”，已安装且版本一致显示“已安装”，远程版本高于本地版本显示“更新”。版本比较规则与系统应用市场一致。

市场内容区顶部提供「首页 / 分类」子 Tab，默认进入「首页」：

- **首页**：读取市场首页聚合接口（`/api/admin/market/home`）渲染四个区块——「不可错过的应用」（随机 2 行，图标+名称网格，每行 6 个）、「官方精选」（精选应用优先、不足 2 行按下载量补全）、「装机必备 / 官方精选 / 运营推荐」（市场服务端推荐位应用，每列 5 个，图标+名称+两行描述）与底部「辅助推荐」网格（推荐位 `aux`，2 行）。点击任意应用卡片进入详情页。
- **分类**：原有的分类浏览。分类 Tab 依据市场分类接口（`/api/admin/market/categories`）渲染，切换分类时按分类代码重新分页加载；搜索框仍为本地过滤，作用于已加载的卡片（搜索时自动切换到分类 Tab）。

### 已安装应用列表

列表按“应用信息 / 状态 / 操作”三列展示，顶部提供搜索、状态筛选（全部状态、已启用、已禁用）和“上传安装”按钮，统计行显示应用总数与已启用数量。“未安装”和“应用市场”界面只保留搜索，不提供状态筛选。应用列表数据直接来自系统应用管理接口 `GET /api/admin/apps`，与传统后台“应用管理”保持同一数据源与排序。

- 状态列只显示启用开关，开关状态通过提示文字和无障碍标签表达；操作后会刷新应用状态与后台菜单。
- “打开”进入该应用的 WebOS 窗口；应用没有可访问的后台菜单时按钮为禁用态。
- “手动”打开上传弹层选择本地 `.zip` 升级包完成手动升级，“导出”直接将应用代码与数据表打包下载。
- “更多操作”菜单提供管理入口（应用有可访问后台菜单时）、备份、文档、设置（存在 `config_groups` 时）和卸载（非系统应用）：

| 操作 | 行为 |
|---|---|
| 管理入口 | 单独把该应用的某个菜单添加到桌面或移出桌面 |
| 备份 | 查看历史备份并新建三步分卷备份；可下载备份文件、按备份执行三步恢复、删除备份；支持导入恢复（上传 .zip 备份包或从服务器备份目录选择） |
| 文档 | 三栏预览应用 `doc/` 目录下的 Markdown 文档（左侧文件树、中间正文、右侧目录），支持下载当前文档 |
| 设置 | 读取并保存应用 `config_groups` 配置项 |
| 卸载 | 输入应用名称确认后卸载；需先禁用应用，在禁用提示中确认后会自动进入卸载确认，卸载成功后自动移除该应用的桌面快捷方式与任务栏固定图标 |

上述操作与传统后台“应用管理”页面（`resources/views/admin/app/index.blade.php`）完全一致，直接复用系统应用管理接口（`/api/admin/apps/*`），不重复实现安装器逻辑。“上传安装”用于安装新的应用包，与手动升级共用同一个拖拽/点选上传弹层。

上传弹层不再自动弹出系统文件选择框，改为点击虚线区域或拖拽 `.zip` 文件进去；选中后展示文件名与大小，可点右侧叉号移除重选，非 `.zip` 会被前端拦下。上传结果直接展示后端返回的提示语（如“应用已从 1.7.3 升级到 1.8.0”），手动升级成功后会询问是否立即启用应用。

备份弹窗顶部工具栏与传统后台一致：左侧显示“共 N 条备份记录”与“导入恢复”按钮，右侧为“立即备份”；下方列出该应用的历史备份（备份时间、版本、数据表数、文件大小、状态）。“立即备份”可设置分卷大小（1-100MB，默认 2MB），随后按“准备 → 逐表分页导出 → 完成”三步执行，进度条实时显示当前处理的表与行数。备份列表中的“恢复”按三步（准备 → 逐表按 offset 恢复 → 完成）执行，单表失败最多重试 3 次（业务错误间隔 1 秒、网络错误间隔 2 秒）。“导入恢复”提供两个 Tab：上传文件（拖拽或点选 .zip 备份包，上传到服务器后走分步恢复）与从服务器选择（列出 `/storage/app_backups/{appId}/` 目录下的 .zip 文件，点击恢复）。每应用最多保留 10 份备份，超出部分由后端在备份完成时自动清理。

文档预览的右侧目录由正文标题自动生成，点击目录项平滑滚动到对应标题，滚动正文时目录高亮同步跟随；代码块使用 highlight.js 高亮（`github-dark` 主题，语言包 bash / css / javascript / json / php / sql / xml，与传统后台一致），`vue`、`html` 标记统一按 `xml` 处理。

安装弹窗会先读取应用清单并自动判断菜单终端：声明 `menus` 时显示“后台菜单挂载位置”，声明 `user_menus` 时显示“用户端菜单挂载位置”，声明 `home_menus` 时显示“前端菜单挂载位置”。每个终端都可选择现有顶级菜单；不选择则作为独立顶级菜单安装。若应用只声明后台菜单，弹窗只显示后台挂载项。

安装弹窗默认把应用添加到系统菜单（不再提供“添加到系统菜单”选项）；“创建桌面快捷方式”为可选操作，默认不勾选，勾选后 WebOS 会在安装完成且存在可访问的后台菜单时，把应用首个后台菜单入口固定到桌面。仅声明用户端或前端菜单的应用不会创建 WebOS 桌面快捷方式。安装弹窗采用 layui 精简风格（纯色遮罩、无毛玻璃特效）。安装成功后与传统后台“应用管理”一致，会弹出确认框询问“是否现在启用当前应用”，点击“是”后直接启用并刷新列表。

- 点击任务栏地球图标，浏览器新标签页打开当前站点前台首页。

## 七、卸载与回滚

通过后台卸载时，`Install::uninstall()` 会回滚应用迁移并删除工作区表，安装器同时移除应用菜单、权限与已发布资源。

人工回滚前必须备份数据；脚本位于 `Database/rollback.sql`。该操作会删除所有管理员桌面配置，无法自动恢复。

## 八、常见问题

### 页面一直停留在加载状态

检查应用是否已启用、静态资源是否已发布，并在浏览器开发者工具中确认工作区与目录接口未返回 401/403/500。

### 安装应用后没有自动出现桌面图标

目标应用必须声明至少一个可访问的后台菜单，且当前管理员拥有该菜单权限。可在“入口管理”中手动添加已授权菜单。

### 为什么小屏幕显示提示页

多窗口桌面需要足够的横向空间。宽度低于 960px 时会显示视口提示，避免窗口控件被遮挡。
