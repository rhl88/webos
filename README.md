# CMSPRO WebOS 管理桌面

`cmspro.webos` 是 CmsPro v5 的桌面式后台入口应用。它复用系统现有菜单、应用市场、通知与账号接口，将后台功能组织为桌面快捷方式、开始菜单、多窗口和任务栏。

## 主要能力

- 从当前管理员有权访问的后台菜单生成开始菜单，左侧按顶级菜单导航，右侧按应用聚合展示。
- 将菜单入口添加到桌面、拖动排序并按管理员持久化。
- 每个应用使用独立窗口，窗口左侧只展示该应用的菜单；支持聚焦、拖动、缩放、最小化、最大化和关闭。
- 任务栏采用紧凑尺寸，可按管理员设置到屏幕上、下、左、右四个方向。
- 在应用中心查看市场、已安装、未安装、更新、操作记录和入口管理。
- 安装应用时选择系统菜单挂载位置，并可在安装后创建桌面快捷方式。
- 集成后台通知中心、账号菜单、锁屏和退出登录。

## 安装

在后台应用管理中找到“WebOS 管理桌面”，执行本地安装并启用。应用菜单默认以新窗口方式打开 `/admin/cmspro/webos`。
